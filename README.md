# MediScribe 🩺💬

MediScribe is a system that transcribes doctor–patient conversations in real time and generates prescription recommendations based on the dialogue.  
It aims to streamline clinical documentation, improve accuracy, and enhance the patient experience.

## 🚀 Features
- **Real-time Transcription** of doctor–patient conversations
- **Disease Prediction & Prescription Generation**
- **Secure Storage** of audio and transcription data
- **Doctor & Patient View** – Both can see the conversation live
- **Scalable Backend** for storing and retrieving consultation data

## 🛠️ Tech Stack
- **Frontend:** React / HTML / CSS / JavaScript
- **Backend:** Python (Flask / FastAPI)
- **Machine Learning:** Speech-to-Text API, Disease Prediction Model
- **Database:** MongoDB / PostgreSQL
- **Cloud Storage:** AWS S3 (or similar)

## 📂 Project Structure
│── backend/ # Python backend API
│── frontend/ # Web interface
│── models/ # ML models for transcription & prediction
